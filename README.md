# Artgiss - Portafolio de Ilustración Digital 🎨

**Artgiss** es un portafolio visual profesional desarrollado para una ilustradora digital. Este proyecto fue creado con **React** y **Material UI**, con el objetivo de ofrecer una experiencia elegante, funcional y totalmente responsiva que permita presentar ilustraciones, servicios y redes sociales de forma atractiva y ordenada.

## ✨ Características

- Diseño moderno y responsivo
- Secciones dedicadas para ilustraciones, servicios y contacto
- Integración con redes sociales
- Navegación fluida y experiencia visual enfocada en el arte

## 🛠️ Tecnologías utilizadas

- [React](https://reactjs.org/)
- [Material UI](https://mui.com/)
- [React Router](https://reactrouter.com/) 
- [Framer Motion](https://www.framer.com/motion/)
